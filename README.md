# Math Tools
Small utility scripts built alongside my math self-study

## degrees_to_radians.py
Converts degrees to radians.

Degrees: 180
→ 180.00 degrees are 3.141593 radians
Degrees: 90
→ 90.00 degrees are 1.570796 radians

## exponential_growth.py
Shows the growth/decay of the input entered after a time n 

Base: 1000
growth factor (example 0.05 for 5%): 0.05
Timesteps: 3
→ After 1 Timestep: 1050.00
→ After 2 Timesteps: 1102.50
→ After 3 Timesteps: 1157.63

## matrix_multiplication.py (numpy is needed)
Ask for 2 matrices und multiplies them

Rows A: 2, Cols A: 2
Row 1: 1 2
Row 2: 3 4

Rows B: 2, Cols B: 2
Row 1: 5 6
Row 2: 7 8

A x B =
[[19 22]
 [43 50]]

## trigonometry_calc.py
Calc for trigonometric functions(sin, cos, tan)

Angle in Degree: 45
→ sin(45°) = 0.7071
→ cos(45°) = 0.7071
→ tan(45°) = 1.0000
